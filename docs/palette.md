# カラーパレット

写真1枚から最大5色を取り、ダブルクリックで開くレビュー画面に出す。
実装は `photofinder/palette.py`。しきい値の数値はそこが定義元で、この文書はそれと揃えてある。

鳥の「青い鳥」タグ（`colors.py`、SigLIP）とは別機能である。パレットは検索タグにも全文検索にも入れない。

## 保存するもの

同じ `photofinder.db` の `photo_palette`（スキーマ v8）。写真1枚につき1行。

| 列 | 内容 |
|---|---|
| `photo_id` | 写真 ID |
| `version` | `PALETTE_VERSION`（現在 1）。`photos.ml_version` とは別 |
| `colors_json` | `[{"hex":"#3A6B4C","ratio":0.42}, ...]`。最大5件 |
| `updated_at` | 更新時刻 |

`ratio` は縮小後の画素数に対するその色の割合。面積が小さい色は捨てるので、合計は 1 未満になりうる。

印象の文章は保存しない。`GET /api/photos/{id}` が hex からその場で組む。文言やしきい値の変更だけなら `PALETTE_VERSION` を上げなくてよい。色の選び方を変えたときだけ上げる。上げると次回スキャンでパレット行だけを作り直す。

`ML_VERSION` は上げない。上げると YOLO・OCR・埋め込みまで全写真が再実行される。

フルバックアップは DB ごと保存するので、この表も一緒に残る。写真を消すと `ON DELETE CASCADE` で行も消える。

## いつ計算するか

新規、またはファイルが変わって `extract_one` が走る写真は、そのとき既に開いている作業画像から計算する。原本の読み増しはない。失敗しても写真の `index_state` は変えない。行が無いまま残り、次のスキャンでやり直す。

取り込み済みでファイルが変わっていない写真は、スキャンの別フェーズ（進捗表示は「カラーパレットを作成中」）で埋める。対象は `index_state='complete'` かつ、パレット行が無い、または `version` が `PALETTE_VERSION` より古いものだけ。

入力の優先順:

1. 保存済みサムネイル（長辺 320px の WebP）
2. 保存済みプレビュー（長辺 1600px）
3. どちらも無いときだけ原本（RAW は埋め込みプレビュー）

パレット作成の失敗は、その写真の検索可否を変えない。停止を押すと、未処理分は行が無いまま残り、次のスキャンで続く。

ノイズ画像で測った抽出時間は 1 枚あたり約 50ms（長辺 96px、CPU）。平坦な写真は反復が早く終わる。ML の再抽出（1 枚あたり数秒）とは別の処理である。

## 抽出

人の見た目に合わせるため、RGB の距離では分けない。RGB では暗い色が割れやすく、近い色が離れて見える。使う空間は OKLab（Björn Ottosson。ユークリッド距離が、人が感じる色差に近い）。追加ライブラリは無い。Pillow と NumPy だけ。

1. 長辺 `SAMPLE_EDGE`（96px）まで BOX 縮小する。呼び出し側の画像は縮小しない。
2. 画素を sRGB から OKLab へ変換する。
3. 固定シードの k-means++ で `K_INIT`（8）クラスタに分ける。反復は最大 `KMEANS_ITERS`（12）。同じ画像なら初期値が同じになる。
4. 中心の距離が `MERGE_DISTANCE`（0.05）未満のクラスタは、画素数の多い側へ畳む。霧や単色に近い写真は、グレーが5色に割れない。
5. 割合が `MIN_SHARE`（4%）未満のクラスタは面積枠から外す。全部それ未満なら、最大の1色だけ残す。
6. 面積の大きい順に最大4色を採る。
7. まだ選ばれていない色のうち、割合が `ACCENT_MIN_SHARE`（1.5%）以上かつ彩度が `ACCENT_MIN_CHROMA`（0.08）以上で、いちばん鮮やかなものを5枠目に足す。赤い一点や花のような、面積は小さいが見て気づく色を残すため。該当が無ければ、面積5位を足す。
8. 改めて面積順に並べ、中心を sRGB に戻して `#RRGGBB` にする。OKLab の中心が sRGB の外に出た成分は 0–255 に切る。

表示の印象は、この量子化後の `#RRGGBB` から計算する。画面に出ているコードと文章がずれない。

## 印象文

測定された感情ではなく、色票や色名の研究で繰り返し出た対応を、明度 L・彩度 C・色相 h（OKLCH）に割り当てた表示用の文である。写真がその場で引き起こす気分そのものではない。画面の文は、その対応を日常の言葉にしたもので、快・覚醒・支配感といった尺度の名前は出さない。

参照した主な研究:

- Valdez & Mehrabian (1994), *Journal of Experimental Psychology: General*. 快は明度と彩度が高いほど上がる。覚醒は彩度が高いほど上がり、明度が高いほど下がる。支配感は暗いほど、また彩度が高いほど上がる。色相の効果は明度・彩度より小さい。黒の「圧がある」は、この支配感を日常語にしたもの。
- Ou, Luo, Woodcock & Wright (2004), *Color Research & Application*. 文化差が小さい尺度は暖寒・重軽・活動性・硬軟。活動性は彩度、重さは明度、暖寒は色相と彩度に載る。好き嫌いと緊張は英中で差があったので、温度・重さ・活動の3語には使わない。Ou ら (2018) は日本を含む12地域で暖寒・重軽・活動性を再推定している。桃の「柔らかい」は硬軟（明るいほど柔らかい）による。
- Wilms & Oberfeld (2018), *Psychological Research*. 高彩度かつ明るい色は快も覚醒も高く、皮膚電気反応も強い。色相の覚醒は青・緑より赤が高い。青の快の優位は高彩度のときだけはっきりした。
- Jonauskaite ら (2020), *Psychological Science*. 30か国で、12の色名と20の感情語の対応。赤は愛情と怒り、黄は喜び（楽しさもある）、橙は喜びと楽しさ、青緑は喜びと心地よさ、桃は愛情・喜び・心地よさ、茶は嫌悪、白は安堵、灰は悲しみとがっかり、黒は悲しみ・恐れ・怒りなど負の感情が広い。青の寂しさは主対応ではなく、ときどき出る側。
- Jonauskaite & Mohr (2025), *Psychonomic Bulletin & Review*. 132論文の整理。明るい色は快、暗い色は不快に結びつきやすい。赤は力があり、愛情・情熱と怒り・緊張の両方がある。黄・橙は快で、気持ちが動く。青・緑・青緑・白は快で、落ち着いている。桃は快。紫は力と誇らしさで、落ち着きと恐れの報告も混在する。灰は退屈・がっかりのように力が弱く沈む。黒は恐れや怒りのように力が強く沈む。多くは色単語や色票への連想で、その色を見るとその感情になる、という意味ではない。
- Palmer & Schloss (2010), *PNAS*. 茶や暗い黄は好まれにくい。嫌いなものと結びつく色（茶では汚物や腐った食べもの）だから、という説明。茶の一文は、この好みと、上の嫌悪の対応による。
- Elliot & Maier (2014), *Annual Review of Psychology*. 赤の意味は成績場面と親和場面で逆向きになるなど、文脈依存が強い。写真の色見本に「赤は危険」とは書かない。

明度と覚醒の向きは Valdez ら（明るいと覚醒が下がる）と Wilms ら（明るい高彩度で覚醒が上がる）で一致しない。活動性の語は、両者が一致している彩度側だけを使う。明度は重さに置く。

色のイメージとして広まった語でも、上の対応と合わないものは使わない。紫の「格式」、茶の「地に足がついた」はここに入る。紫は力と誇らしさが中心で、落ち着きと恐れも報告される。茶は嫌悪と結びつき、好まれにくい。緑と青緑の一文は同じである。2020年の調査では青緑に喜びと心地よさも出ているが、2025年の整理は緑・青緑・青を同じ群に置いている。青だけ、副次的な寂しさを一文の後半に残す。

明るい色は快、暗い色は不快に寄りやすい。色名としての灰は低覚醒で負の感情と結びつくが、これは中間から暗い灰の話である。L が `0.75` を超える灰は、重さの語がすでに「軽い」であり、沈んだ一文は出さない。温度・重さ・活動の3語だけになる。

各色は3語を出す。

| 軸 | 決め方 | 語句 |
|---|---|---|
| 温度 | `C * cos(h - 50°)`。絶対値が `WARM_SCORE`（0.008）未満、または `C < 0.03` | 暖かみがある / 涼しさがある / 温度は感じにくい |
| 重さ | L。`0.45` 未満 / `0.75` 超 | 重い / 重くも軽くもない / 軽い |
| 活動 | C。`0.03` 未満 / `0.12` 未満 / それ以上 | 静か / 穏やか / 活発 |

色名と、添える一文:

| 名前 | 条件の目安 | 一文 |
|---|---|---|
| 白 | C < 0.03 かつ L ≥ 0.92 | ほっとした気持ちや、希望と結びつきやすい。 |
| 黒 | C < 0.03 かつ L ≤ 0.22 | 悲しみや恐れ、怒りと結びつきやすい。暗いほど、圧がある。 |
| 灰（明るい） | C < 0.03 かつ L > 0.75 | 出さない（3語だけ） |
| 灰 | C < 0.03 の残り | 退屈や悲しみ、がっかりした気持ちと結びつきやすい。 |
| ベージュ | L ≥ 0.80、C < 0.08、色相 40–115° | 出さない（3語だけ） |
| 茶 | L < 0.55、C < 0.16、色相 30–115° | 嫌悪と結びつきやすく、あまり好まれない。 |
| 桃 | L ≥ 0.70、色相が赤〜赤紫（≤45° または ≥330°） | 愛情やうれしさがあり、明るくて柔らかい。 |
| 赤 | 上に当てはまらない赤 | 愛情や情熱があり、怒りや緊張もある。どれも力が強い。 |
| 橙 | 色相 40–75° | 楽しさや、わくわくする感じが出る。 |
| 黄 | 色相 75–115° | うれしさがまっさきに来る。楽しさもある。 |
| 緑 | 115–165° | 落ち着いていて、心地よい。 |
| 青緑 | 165–210° | 落ち着いていて、心地よい。 |
| 青 | 210–275° | 落ち着いていて、心地よい。寂しさと結びつくこともある。 |
| 紫 | 275–330° | 誇らしさや力が出る。落ち着きとも、恐れとも言われる。 |

茶・桃・白・黒と、L が `0.75` 以下の灰は、彩度が低くても一文を出す。それ以外は、C が `0.12` 未満のとき一文を出さない。彩度が足りない色に、その色相の感情語を重ねないため。色相の角度は OKLab の `atan2(b, a)` で、純赤が約 29°、黄が約 110°、緑が約 143°、青が約 264° である。

## 表示

レビュー画面ではパレットを画像の外に置く。画像には重ねない。表示中はダイアログを画面内の高さに固定し、画像を縮めて下の帯、または右の列の分を空ける。ファイル名は画像の下端に重ねたままにする。

設定 `palette_layout`:

| 値 | 配置 |
|---|---|
| `horizontal`（既定） | 色を横に並べ、画像の下に置く |
| `vertical` | 色を縦に並べ、画像の右に置く |
| `hidden` | 出さない |

`palette_note`（既定は表示する）は、表示しているときだけ効く。オンなら温度・重さ・活動の3語と、色相の短い文章を出す。オフなら色見本、`#RRGGBB`、割合、色名だけ。

未作成の写真には帯も列も出さない。以前の `show_palette=0` は、`palette_layout` が未保存のあいだ `hidden` として読む。
